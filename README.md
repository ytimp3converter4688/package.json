# 🔮 AI Palm Reader – Cosmic Guidance App (PWA)

A premium, production-grade Progressive Web App (PWA) offering AI-powered palm reading, tarot guidance, and astrological insights. Built with React, Vite, and OpenRouter AI.

## 🌟 Features

- **AI Palm Analysis**: Computer vision analysis of hand lines (Heart, Head, Life, Fate).
- **Tarot Reading**: Interactive 3-card spreads for Love, Career, and Growth.
- **Daily Guidance**: Personalized daily energy, lucky elements, and advice.
- **Horoscope**: Daily astrological insights for all zodiac signs.
- **AI Spiritual Chat**: Context-aware chat for spiritual reflection (Non-predictive).
- **Multi-language Support**: English, Hindi, Spanish, French, Italian, Korean.
- **PWA Ready**: Installable on iOS and Android with offline capability.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: CSS Modules, Glassmorphism Design System, Framer Motion
- **AI Integration**: OpenRouter API (Vision + Text Models)
- **State Management**: React Context API
- **PWA**: vite-plugin-pwa
- **Icons**: Lucide React
